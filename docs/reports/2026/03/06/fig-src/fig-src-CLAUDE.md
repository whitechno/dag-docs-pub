# Instructions to adjust hamiltonian_cycle figures

## c=1

Arc 212->210 touches 201. Make the arc bow less so that it passes between 201
and 211 with enough clearance.

Arc 211->011 touches 121. Make the arc bow less so that it passes between 121
and 111 with enough clearance.

## c=2

Arc 212->012 touches vertex 102. Adjust it so that 102 is on the right of the
arc with enough clearance.

Arc 210->010 touches vertex 120. Adjust it so that 120 is on the left of the arc
with enough clearance.
